# MAGIKALEA — landing page prototype

## Estructura
- `index.html` — página completa.
- `styles.css` — diseño responsive.
- `script.js` — scroll/parallax ligero.
- `assets/` — arte proporcionado para el prototipo.

## Antes de publicarla
Busca en `index.html`:
- `TU_LINK_STEAM`
- `TU_LINK_TWITTER`
- `TU_LINK_DISCORD`

y reemplázalos por los enlaces reales.

También reemplaza los nombres de la sección "Artistas" por los créditos definitivos.

## Estilo
La página usa:
- azul noche + azul mágico
- dorado tipo marco de cartas
- tipografía serif/fantasía para títulos
- paneles inspirados en la UI del juego
- fondos e ilustraciones del material proporcionado
- diseño responsive para móvil

No necesita backend: puedes subir estos archivos directamente a GitHub Pages, Firebase Hosting, Netlify o Vercel.
